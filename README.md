# React SPA Portfolio

A simple Single Page Application (SPA) portfolio built with **React**.

## Features

* Home page
* About section
* Projects section
* Skills section
* Contact section
* Responsive design
* Simple and clean UI

## Technologies

* React
* JavaScript
* HTML
* CSS
* Vite

## Installation

```bash
git clone <your-repository-url>
cd <project-folder>
npm install
npm run dev
```

Open the local URL shown in your terminal.

## Build

```bash
npm run build
```

## Project Structure

```text
src/
├── components/
├── pages/
├── assets/
├── App.jsx
└── main.jsx
```
